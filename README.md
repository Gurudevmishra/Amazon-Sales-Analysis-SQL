## 🧹 Data Cleaning and Validation

Data quality is essential for accurate reporting and business analysis.

### 1. Missing Value Detection

Identify records containing missing information.

```sql
SELECT *
FROM amazon_raw
WHERE `Order ID` IS NULL
   OR Product IS NULL
   OR `Quantity Ordered` IS NULL
   OR `Price Each` IS NULL
   OR `Order Date` IS NULL;
```

### 2. Duplicate Record Detection

Identify repeated transaction records.

```sql
SELECT
    `Order ID`,
    Product,
    `Quantity Ordered`,
    `Price Each`,
    `Order Date`,
    COUNT(*) AS duplicate_count
FROM amazon_raw
GROUP BY
    `Order ID`,
    Product,
    `Quantity Ordered`,
    `Price Each`,
    `Order Date`,
    `Purchase Address`
HAVING COUNT(*) > 1;
```

### 3. Invalid Value Checks

Identify records containing invalid quantities or prices.

```sql
SELECT *
FROM amazon_raw
WHERE `Quantity Ordered` <= 0
   OR `Price Each` <= 0;
```

**Note:** These queries are examples of validation checks. The exact data-cleaning steps and results are documented in the project SQL script.

## 📊 Exploratory Data Analysis

### 1. Total Sales Revenue

**Business Question:** What is the total revenue generated by sales transactions?

```sql
SELECT
    ROUND(
        SUM(`Quantity Ordered` * `Price Each`),
        2
    ) AS total_revenue
FROM amazon_raw;
```

### 2. Total Orders

**Business Question:** How many unique orders are present?

```sql
SELECT
    COUNT(DISTINCT `Order ID`) AS total_orders
FROM amazon_raw;
```

### 3. Total Units Sold

**Business Question:** How many units were sold?

```sql
SELECT
    SUM(`Quantity Ordered`) AS total_units_sold
FROM amazon_raw;
```

### 4. Top 10 Products by Revenue

**Business Question:** Which products contribute the most to total revenue?

```sql
SELECT
    Product,
    ROUND(
        SUM(`Quantity Ordered` * `Price Each`),
        2
    ) AS total_revenue
FROM amazon_raw
GROUP BY Product
ORDER BY total_revenue DESC
LIMIT 10;
```

### 5. Product-wise Order Quantity

**Business Question:** Which products have the highest sales volume?

```sql
SELECT
    Product,
    SUM(`Quantity Ordered`) AS units_sold
FROM amazon_raw
GROUP BY Product
ORDER BY units_sold DESC;
```

## 🚀 How to Run This Project

1. Download or clone the GitHub repository.
2. Open MySQL Workbench.
3. Create the database:

```sql
CREATE DATABASE IF NOT EXISTS amazon_portfolio_project;
```

4. Import `Amazon_Sales_Dataset.csv` into MySQL using the Table Data Import Wizard.
5. Ensure the table is named `amazon_raw`.
6. Open `Amazon_Sales_Analysis.sql`.
7. Select the correct database and execute the queries.
8. Review the results and business insights.

**Note:** Revenue calculations assume that quantity and price fields have numeric data types and contain valid values.
